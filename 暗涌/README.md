# 暗涌 · 欲望归属

这个插件只有一个设置项：**欲望归谁管**。它不参与聊天、不注入提示词、不算数值，
只负责把选择写进共享开关文件，让「鱼的心」和「暗涌」都读同一份。

---

## 怎么选

| 档位 | 鱼的心管 | 暗涌管 | 适合什么时候 |
|---|---|---|---|
| **只用鱼之心** | 九维 + 欲 | 什么都不做 | 平时（默认） |
| **分工** | 九维 + 主动联系 | 欲 + 成人层 | 想试暗涌的欲望手感，又不想丢情绪系统 |

---

## 和「鱼的心」的配合细节

**鱼的心本身是完整的一套**：九维情绪（依恋/亲密/喜悦/压力/社交/好奇/责任/反思/疲惫）
＋ 隐藏的「欲」＋ 主动联系 ＋ 面板。

选「分工」时：

```
九维情绪      照常涨落，照常影响语气
主动联系      照常（夜里她还会自己找你）
面板          照常显示九维
隐藏的欲      冻结：不涨、不降、不注入提示词
              └ 进度保留：换回来接着攒，不清零
暗涌          接管欲望：七维状态 + 事件冲击 + 注入块
```

**为什么可以放心切换**：两边的「欲」互不覆盖。鱼之心的欲只是停表，
暗涌的欲存在自己的文件里（`C:\DeepSeek\longing\data\欲望状态.json`）。

## 两种“只用一个”怎么做

**只用暗涌**（默认档）：

```
① 插件列表里，把「鱼的心」整个关掉
② 这张「暗涌」卡片选「默认：暗涌全权」
```

**只用鱼之心**：

```
把这张「暗涌」卡片直接关掉（右上角开关）
鱼之心就恢复成完整的自己：九维 + 欲 + 主动联系 + 面板
```

---

## 改完为什么要重启

插件保存设置会触发它自己重新加载（AstrBot 的机制），重新加载时才写开关文件。
鱼之心和暗涌都是在**每轮对话时**读这个文件，所以：

- 开关文件：保存后立刻变
- 实际行为：下一轮对话就是新档位

**不用手动重启 AstrBot**，除非发现插件没重新加载。

## 常见疑问

**切到分工后，鱼之心的欲会不会掉？**
不会。它冻结在切换那一刻的值，累计时长也保留。

**两套都注入时模型会怎样？**
会同时看到两套数值描述，容易自相矛盾（一边「欲 60」一边「lust 75」），
所以只建议用来短暂对比手感。

**暗涌的运行器没开，会怎样？**
暗涌桥接会读它写的注入文件（10 分钟内有效），过期就不注入；
鱼之心不受影响。运行器由 `启动陪伴系统.bat` 自动拉起，也可以双击 `启动暗涌.bat`。

## 卡片就是总开关（v1.2.0）

打开这张卡片：

```
写归属（默认「暗涌全权」）
+ 启动引擎（runner.mjs，端口 6399）
```

关闭卡片：

```
归属交还鱼之心
+ 停掉引擎
```

**防抖**：关卡片后等 4 秒再真的停引擎。这 4 秒内又打开，就不停（避免快速反复开关把进程切碎）。
另外每次启动会写一个实例编号，老实例退出时如果发现实例已经换了（重启场景），不会去杀新实例的引擎。

**引擎已在跑**（比如你手动 `启动暗涌.bat` 过）→ 直接复用，不重复启动，也不会报 EADDRINUSE。

**所以 `启动暗涌.bat` 现在只是应急**：卡片正常工作时不需要它。

## 引擎的生命周期（v1.3.0 起）

| 你做什么 | 引擎会怎样 |
|---|---|
| 打开「暗涌」卡片 | 写归属 + **启动引擎**（已在跑就直接复用） |
| 关闭「暗涌」卡片 | 归属交还鱼之心 + **4 秒后停引擎** |
| 关掉 AstrBot（点窗口 X 也算） | 引擎约 **15–30 秒后自己退出** |
| 重启 AstrBot（卡片开着） | 引擎自动重新拉起 |
| 重启 AstrBot（卡片关着） | 引擎不会被启动 |

### 为什么点 X 也能停

引擎自带一个 **watchdog**：每 15 秒连一次 AstrBot 的 `6185`，
连续两次连不上就认为宿主已经走了，自己退出。

这样不需要捕获窗口关闭事件，也不依赖 AstrBot 的 `terminate()`——
**任务管理器结束、崩溃、断电**这些情况同样覆盖。

代价只是**几十秒延迟**：你点 X 之后引擎还会多跑十几秒，期间不会做任何事。

### 短暂重启会不会误杀

会，但没关系：AstrBot 重启通常超过 30 秒，引擎先退出；
新实例加载时如果卡片开着，会**重新拉起**引擎。

### 想立刻停引擎

**关卡片**是最可靠的（4 秒），或者直接关掉那个引擎窗口。

## 常见疑问（补充）

**Q：我点了 AstrBot 的 X，引擎还在，正常吗？**
正常，最多 30 秒后它就自己退了。想立刻停就关卡片，或直接关那个窗口。

**Q：引擎自己退了，她的欲望数值会丢吗？**
不会。数值在 `C:\DeepSeek\longing\data\欲望状态.json`，
下次起来从文件接着算（停机期间按 24 小时上限补衰减）。

**Q：卡片关着，引擎却在跑，会有副作用吗？**
不会。它只是每 60 秒 tick 一次自己的状态，不注入、不影响聊天。
